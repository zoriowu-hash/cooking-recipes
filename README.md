# Cooking Recipes 🍳

A personal collection of recipes — recorded in the order I add them.

## Structure

- `recipes/` — one Markdown file per recipe, named `NNN-slug.md` (e.g. `001-lentil-soup.md`), numbered in the order added.
- `recipes/breakfast/` — breakfast ideas, same naming and numbering.
- `recipes/000-template.md` — the template every new recipe follows.

## Recipe template

Each recipe file has:

- Title + one-line description (serves / prep / cook time)
- Ingredients with quantities
- Numbered steps
- Notes (source, variations, tips)

## Workflow

Send Zorio a recipe — text, a link, or a photo — and it gets recorded here in the next free number, then committed and pushed.
